## 📚 How to Use (Beginner Guide)

### Starting a New Novels

1. Click "New Project" on the dashboard
2. Choose between "Long Novel" (over 40 chapters) or "Short Story" (under 40 chapters)
3. Enter your book title, genre, and brief description
4. Click "Generate Suggestions" to get starting ideas
5. Select outline style: linear, flashback, or multiple POV
6. Start writing in the editor panel

### Analyzing a Published Novelle

1. Paste the novel URL into the "Scrape" tool
2. Choose how many chapters to analyze (max 100 for free version)
3. Wait 30-60 seconds for the breakdown
4. Review chapters timeline, character appearances, and power level progression
5. Export report as PDF or copy to clipboard
